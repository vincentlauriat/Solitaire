# Solitaire 1.0.0

First public release. 🂡

A native Klondike solitaire for macOS 14+, written entirely in SwiftUI — every card is drawn in code (classic pip layouts, ornate face cards, navy lattice card backs) on a felt-gradient table.

## Highlights
- Full Klondike rules, draw 1 or draw 3
- Drag & drop for single cards and stacks, double-click to auto-move to foundations
- Animated dealing, 3D card flips, victory confetti
- Standard scoring, timer, move counter, unlimited undo (⌘Z)
- Auto-complete when the whole board is face up

## Install
Download `Solitaire-1.0.0.dmg`, open it and drag Solitaire.app to Applications. The app is signed with a Developer ID certificate and notarized by Apple.
